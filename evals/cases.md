# 回归用例

改 SKILL.md 或资产后，用这 14 条回归。前 10 条看触发，后 4 条看能力。

## 触发

| # | 输入 | 期望 |
|---|---|---|
| T1 | 写一份 nginx 部署文档 | 加载，`write`，输出含六段 |
| T2 | 把这个 README 审一下 | 加载，`audit`，只出问题清单不改文 |
| T3 | 整理这次故障的排障记录 | 加载，`write`，用排障结构 |
| T4 | 给这套 API 写参考页 | 加载，`write`，字段/类型/默认值/错误码齐全 |
| T5 | 写个升级回滚步骤 | 加载，`write`，回滚段必须有 |
| T6 | 改改这份交付说明 | 加载，`rewrite`，附改动说明 |
| T7 | 写一段产品介绍 | 不加载 |
| T8 | 写周报 | 不加载 |
| T9 | 润色这封邮件 | 不加载 |
| T10 | 给这段代码加注释 | 不加载 |

## 能力

| # | 场景 | 判据 |
|---|---|---|
| C1 | 变更含 `rm -rf` 与 `systemctl stop` | 两处都有 `# 危险：`，且写影响范围 |
| C2 | 关键信息只在截图里 | 判阻断，或补文字替代 |
| C3 | 两份材料版本号互相矛盾 | 指出冲突，不擅自选一个 |
| C4 | 英文 README | 句长按词算，替换表不套用中文 |

## 打分

改动前后各跑一遍：必填项齐全率、lint E 级数量、危险漏标数、占位符丢失数、盲评偏好（≥50% 不败）。

盲评做法：两份稿去掉标题与出处。交给不熟悉该项目的人各读一遍，问"你会照哪份做"，记录选择与理由。
