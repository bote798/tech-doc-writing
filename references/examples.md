# 反例 → 正例（12 组）

本文件是反例集，默认跳过 lint（见文件末尾的开关注释）。每组只改一处，便于对照。

<!-- lint:off -->

## 1. 行尾注释

反例：

```bash
systemctl restart nginx   # 重启服务
```

正例：

```bash
# 目的：重启 nginx 使配置生效
# 幂等：可重复
# 预期：输出 active，退出码 0
systemctl restart nginx
```

## 2. 多命令一行

反例：

```bash
cd /opt/app && git pull && systemctl restart app
```

正例：拆成三个块，或写成 `deploy.sh` 后调用。

## 3. 占位符

反例：把地址里的 xxx 改成 your-host，端口按需改。

正例：把 `<host>` 改成实际地址（见"前提"），端口取 `<port>`。

## 4. 破坏性命令漏标

反例：

```bash
rm -rf /opt/app/logs
```

正例：

```bash
# 目的：清理 7 天前日志
# 危险：删除 /opt/app/logs 下全部文件，不可恢复（已备份到 /backup）
# 幂等：否
# 预期：目录为空
rm -rf /opt/app/logs
```

## 5. 程度词

反例：重启后很快就能访问。

正例：重启后 30 秒内可访问，以 curl 返回 200 为准。

## 6. 模糊时间

反例：近期会升级到新版本。

正例：2026-12-01 前升级到 2.4.1。

## 7. 表格代替步骤

反例：用一张五行表格列出安装顺序。

正例：编号列表，每步一个命令块，每块带预期。

## 8. 一号多动作

反例：`### 1. 安装并启动`。

正例：`### 1. 安装` 与 `### 2. 启动` 分开，各带验证。

## 9. 警告位置

反例：步骤末尾补一句"注意可能丢数据"。

正例：步骤前独立成段："警告：执行前确认已备份 `/etc/nginx`，本操作不可逆。"

## 10. 数字与单位

反例：等待10秒，重试3次。

正例：等待 10 秒，重试 3 次。

## 11. README 缺最小示例

反例：只有安装命令和一串外部链接。

正例：定位一句 → 安装 → 一条命令跑通 → 预期输出 → 文档地图。

## 12. 概念页只有定义

反例：三段"XX 是什么"。

正例：解决什么问题 → 怎么运转（三步）→ 边界与不适用场景。
