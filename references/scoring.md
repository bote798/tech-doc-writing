# 评分锚点

配合 `SKILL.md` 的评分表使用。三份短样例分别对应 2 / 1 / 0 分。

<!-- lint:off -->

## 2 分：对象齐全，有证据

```bash
# 目的：重启 nginx 使配置生效
# 幂等：可重复
# 预期：输出 active，退出码 0
systemctl restart nginx
```

- 第 4 项 2 分：目的与预期都在。
- 第 5 项 2 分：本次无破坏性命令，注明"不存在"。
- 第 6 项 2 分：预期给出输出与退出码。

## 1 分：对象存在，缺一项要素

```bash
# 目的：重启 nginx
systemctl restart nginx
```

- 第 4 项 1 分：有目的，无预期。
- 第 5 项 0 分：重启是变更，缺幂等与影响说明，阻断。
- 第 6 项 0 分：没有判据。

## 0 分：对象缺失或与事实不符

```bash
systemctl restart nginx
```

- 第 4 项 0 分：无目的，无预期。
- 第 5 项 0 分：变更命令无任何标注。

## 判分顺序

1. 先看第 0 项：必填项缺一项即 0 分并阻断，其余项仍记分供参考。
2. 再逐项看 1–11：先找对象，再看要素，最后看证据。
3. 每项写一句证据。写不出证据的，按 0 分。
